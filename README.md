# MAQUINGENIEROS

Página de enlaces y contacto de MAQUINGENIEROS, adaptable a móviles.

## Archivos

- `index.html`: contenido, estilos y enlaces.
- `logooo.avif`: logo.
- `fondo-ondas.svg`: fondo de curvas azules.

Abrir `index.html` en el navegador. Para una vista previa local:

```sh
python -m http.server 8765
```

Visitar http://localhost:8765. El mapa, las fuentes y los iconos requieren conexión a Internet.
